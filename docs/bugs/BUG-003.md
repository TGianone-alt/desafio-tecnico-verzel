# BUG-003 — O cupom é removido por "Esvaziar carrinho", mas permanece aplicado quando o último item é removido e outro é adicionado (comportamento inconsistente)

| Campo | Valor |
|---|---|
| **Severidade** | Baixa |
| **Prioridade sugerida** | Baixa |
| **Classificação** | Ambiguidade / melhoria *(a documentação não define o que acontece com o cupom ao esvaziar o carrinho)* |
| **Camada** | Interface (carrinho) |
| **Cenário relacionado** | EXP-01 (relacionado ao CA05: um cupom por vez) |
| **Ambiente** | https://verzel-store.qa-test-verzel-store.workers.dev · versão 2.3.0 · Google Chrome (versão _preencher_) · Windows · 07/10/2026 |
| **Status** | Aberto |
| **Reproduzível?** | Sempre

## Pré-condições
Carrinho vazio, em uma única aba.

## Passos para reproduzir
**Caminho A: "Esvaziar carrinho"**
1. Adicionar 1 "Mochila Urbana 20L" e aplicar o cupom `bemvindo10`.
2. Clicar em "Esvaziar carrinho".
3. Adicionar 1 "Mochila Urbana 20L" de novo e abrir o carrinho.

**Caminho B: remover o único item**
1. Adicionar 1 "Mochila Urbana 20L" e aplicar o cupom `bemvindo10`.
2. Clicar em "Remover" no único item (o carrinho fica vazio).
3. Adicionar 1 "Mochila Urbana 20L" de novo e abrir o carrinho.

## Resultado esperado
A documentação não define esse comportamento (o CA05 trata só da troca de cupom). Interpretação adotada: o carrinho deveria se comportar de forma **consistente**, ou seja, esvaziar o carrinho por qualquer caminho deveria ter o mesmo efeito sobre o cupom (ou sempre remover o cupom, ou sempre mantê-lo).

## Resultado obtido
- **Caminho A:** o cupom é removido; o carrinho novo começa sem desconto.
- **Caminho B:** o cupom `BEMVINDO10` **continua aplicado** ao novo item (desconto − R$ 10,00 para 1 Mochila). Ele só sai quando o carrinho é esvaziado pelo botão "Esvaziar carrinho".

## Observações
- Não impede a compra nem gera valor incorreto para quem aplicou o cupom na mesma aba; o impacto é de consistência e de expectativa do cliente (ele pode não perceber que o desconto continua válido, ou esperar que ele tenha sumido).
- Sugestão: definir uma regra única (por exemplo, limpar o cupom sempre que o carrinho ficar vazio) e registrá-la na documentação.
- Observação relacionada (usabilidade): "Esvaziar carrinho" age de imediato, sem pedir confirmação.
